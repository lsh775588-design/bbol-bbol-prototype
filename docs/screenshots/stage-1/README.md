# 1단계 에뮬레이터 스크린샷

촬영 환경: Android 에뮬레이터 `Medium_Phone`, 앱은 통합 브랜치(`feat/1-integration`)에서 빌드한 디버그 APK. 서버는 PC에서 `local` 프로파일(H2, 샘플 데이터 포함)로 실행하고 `http://10.0.2.2:8095`로 접속했다. 에뮬레이터 위치는 경복궁 근처(`adb emu geo fix 126.9780 37.5796`). 촬영일 2026-11-13.

| 파일 | 내용 |
|---|---|
| `01-login.png` | 로그인 화면 |
| `02-login-filled.png` | 데모 계정(`demo1@example.com`)을 입력한 로그인 화면. 입력하면 로그인 버튼이 활성화된다 |
| `03-after-login.png` | 로그인 성공 직후 위치 권한 설명 화면(명세 B6: 설명 화면 먼저, 거부하면 둘러보기 모드) |
| `04-permission-dialog.png` | 안드로이드 시스템 위치 권한 창(영문은 에뮬레이터 시스템 언어) |
| `05-map.png` | 지도 화면. 서버에서 받은 주변 장소가 마커로 표시된다. 상단은 카테고리 필터, 하단은 "장소 19곳" |
| `06-place-detail.png` | 마커를 눌렀을 때의 장소 상세(경복궁, HOT, 유적지, 주소, 도착 시 300P, 오늘 방문 완료 아니요, 누적 0명) |
| `07-my-info.png` | 내 정보(이메일, 가입 방식, 가입일, 닉네임 변경, 로그아웃) |
| `08-signup.png` | 회원가입 화면. 비밀번호와 닉네임 규칙 안내, 개발용 인증 토큰 입력칸(debug 빌드에서만 보임) |
| `09-signup-filled.png` | 가입 정보를 입력한 화면. 이메일과 닉네임은 서버의 중복 확인 API 응답("사용할 수 있는 …이에요")이 표시된다 |
| `10-after-signup.png` | 가입 성공 후 자동 로그인되어 지도로 이동한 화면. 서버에서도 새 계정으로 로그인됨을 확인했다 |

## 알아둘 점
- 장소 좌표와 주소는 대략값인 샘플 데이터이고 팀 검토가 필요하다(일부는 실제 매장이 아닌 "샘플" 항목).
- 마커 아이콘이 기본 아이콘(손가락 모양)이다. 디자인은 아직 적용하지 않았다.
- 가입 화면의 이메일 입력은 중복 확인과 개발용 토큰 조립에만 쓰인다. 서버 가입 요청에는 이메일이 없다(이메일 인증 방식 쟁점 2가 정해지면 화면을 다시 정해야 한다).
- 지도 하단에 "장소 19곳"이 표시되지만 현재 화면 범위 밖 장소도 포함한 개수다.
- 상태바 시계 글자가 흰색이라 밝은 배경에서 잘 안 보인다(기능 문제 아님).
- adb로는 한글을 입력할 수 없어서 새 계정 닉네임은 영문(`Explorer1`)이다.
- 내 정보의 닉네임 변경, 가입 실패 문구, 둘러보기 모드(권한 거부)는 이번 촬영에서 직접 눌러 보지 않았다(단위 테스트만 확인).
