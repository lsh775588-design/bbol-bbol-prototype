# 3단계 지도 개선: 스타일과 퀘스트 받기 (feat/9-map-quest)

## 한 일
- 지도 재디자인: 타일에 채도 낮춤/밝게 ColorMatrix 필터, 코드로 그린 보라색 핀(카테고리 아이콘), 선택 핀 확대, 오늘 완료 핀(회색+체크), 받은 퀘스트 핀(금색 고리와 느낌표), HOT 분홍 점, 내 위치 파란 점과 오차 후광, "내 위치로" 버튼, 위쪽 흰색 그라데이션 스크림(상태바와 제목 가독성), 줌(내 위치 16, 둘러보기는 장소 범위에 맞춰 13.5~15), OSM 출처 표기(CopyrightOverlay) 유지.
- 퀘스트 받기 흐름: 핀 탭 -> 상세 시트 "퀘스트 받기" -> "진행 중인 퀘스트"(남은 거리, 반경 안내) + "도착 인증하기" 활성 + "퀘스트 포기하기" -> 인증 성공 시 기록 삭제.
- 받은 퀘스트 기록 `QuestBook`(Clock 주입, 사용자별, Asia/Seoul 자정 만료). 저장은 SharedPreferences. 로그아웃/탈퇴/세션 만료(`AuthSession.clear`)에서 전부 지운다.

## 퀘스트 흐름
1. 핀 탭: 상세 시트에 "퀘스트 받기"만 보인다(도착 인증 버튼 없음).
2. 받기: 앱에만 기록(userId+placeId+오늘 날짜). 핀이 금색으로 바뀌고 하단 알림에 "진행 중 N"이 뜬다. 앱을 다시 켜도 유지된다.
3. 도착 인증: 받은 장소만 가능(ViewModel도 거부). 서버 응답 성공 시 기록 삭제. 오늘 완료한 장소는 "오늘 완료" 비활성(받을 수 없음).
4. 포기: 시트의 작은 글씨 버튼.

## Notion과 달라진 점
- 퀘스트 "받기(수락)" 단계를 **클라이언트에서만** 구현했다. 서버에는 수락 API가 없고 서버는 받은 퀘스트를 모른다(다른 기기와 공유되지 않음, 서버 검증 없음). 서버에서 추적하려면 수락 API가 필요하다.
